# پلانەکانم

ئەپێکی React Native (Expo) بۆ بەڕێوەبردنی پلانەکان.

## دەستپێکردن

```bash
npm install
npm start
```

## تایبەتمەندییەکان

- **لات مۆد** — ڕەنگی ڕووناک و سپی
- **دارک مۆد** — تۆنە زەر و رەش
- گۆڕینی مۆد لەگەڵ پاشەکەوتکردنی هەڵبژاردن

## پێکهاتە

```
src/
  theme/       — ڕەنگەکان و ThemeProvider
  components/  — ThemeToggle و کۆمپۆنێنتەکانی تر
  screens/     — HomeScreen
```

ناوەرۆکی ئەپ لە نامەی دواتردا زیاد دەکرێت.
